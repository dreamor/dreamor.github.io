📖 预训练 (Pretraining)

让模型通过"阅读"海量文本学会语言

🎯 预训练的目的

预训练是让模型学会说话的过程，就像孩子通过大量阅读来学习语言。

💡 类比：完形填空

预训练的任务类似"完形填空"游戏：

今天
天气
?
,
适合
出游

模型需要根据上下文，预测出缺失的词应该是 "很"

📝 Next Token Prediction (下一个词预测)

这是预训练的核心任务，理解了它就理解了预训练的一半：

模型做的事情：给定前面的词，预测下一个最可能的词

# 输入: "今天天气"
input_ids = [BOS, 今天, 天气]

# 模型输出: 每个词作为下一个词的概率
logits = model(input_ids)
# logits[0] = "今天"的下一个词概率
# logits[1] = "天气"的下一个词概率  ← 我们关注这个

# 目标: 让 "很" 的概率尽可能高
target_labels = [今天, 天气, 很, EOS]
输入序列预测位置目标词
[BOS] 今天第2个位置天气
[BOS] 今天 天气第3个位置很
[BOS] 今天 天气 很第4个位置好
[BOS] 今天 天气 很好第5个位置。

🔄 训练流程详解

每个训练步骤（step）是这样进行的：

📥 Step 1: 数据批次采样

从训练集中随机选取一批数据（比如 4 个句子），每个句子最长 512 个 token

batch = [
    "今天天气很好，适合出游。",
    "人工智能是未来的发展方向。",
    ...
]
💡 为什么叫"batch"（批次）？

一次性把 4 个句子输入模型，分别计算 loss，然后求平均得到一个 batch loss，再用这个 batch loss 更新一次参数。

这叫做 Mini-Batch Gradient Descent（小批量梯度下降），是深度学习最常用的方法。

三种梯度下降方式对比

方式每次更新用的样本数优点缺点
SGD 1 个样本 更新快，逃出局部最优 噪声大，不稳定
Batch GD 整个数据集 梯度估计准确，方向稳定 更新慢，需要大内存
Mini-Batch 32/64/128 个样本 平衡速度和稳定性 实际最常用 ✓
🔢 Step 2: 分词 (Tokenization)

将文本转换成数字序列（token ID）

"今天天气很好" → [1024, 3056, 5678, 890, 1234, 567]
🧮 Step 3: 前向传播 (Forward Pass)

将 token 序列输入模型，得到对下一个词的预测概率

# 前向传播
logits = model(input_ids)  # (batch, seq_len, vocab_size)

# 计算交叉熵损失
loss = F.cross_entropy(
    logits[:, :-1, :].view(-1, vocab_size),  # 预测位置
    labels[:, 1:].view(-1)                    # 目标词
)
📉 Step 4: 计算损失 (Loss)

损失衡量预测与真实目标的差距，交叉熵损失公式：

Loss = -∑ p(x) · log(q(x))

其中 p(x) 是真实概率（目标词=1，其他=0），q(x) 是模型预测的概率

🔙 Step 5: 反向传播 (Backward Pass)

计算每个参数对 Loss 的"责任程度"——也就是梯度

💡 通俗理解：谁是"背锅侠"？

Loss 变大了，问题出在谁身上？每个参数都要被"问责"：

  • 梯度大 = 这个参数"责任大"，需要多调整
  • 梯度小 = 这个参数"没什么责任"，少调整
  • 梯度方向 = 告诉你是增加还是减少这个参数

链式法则：从后往前逐层计算，找出"每个参数对 Loss 要付多少责任"

loss.backward()  # 自动计算所有参数的梯度

# 例如：W_q 权重矩阵的梯度
grad_Wq = W_q.grad  # 记录了该如何调整 W_q
# grad_Wq[5, 3] = 0.23 意味着 W_q[5,3] 增大会让 Loss 增大
⚡ Step 6: 参数更新 (Optimizer Step)

根据梯度（责任程度）更新模型参数，犯的错误越大，调整得越多

💡 更新规则：谁的责任大，谁就多改

想象爬山找山谷最低点：

  • 梯度 > 0：增大这个参数 → Loss 增大（往反方向走才能下山）
  • 梯度 < 0：减小这个参数 → Loss 减小（正好下山）
  • |梯度| 越大：说明这个参数"责任越大"，调整幅度也越大
param = param - 学习率 × 梯度

梯度累积：模拟大 Batch

当 GPU 显存不够时，可以用梯度累积来模拟大 batch 训练：

# 梯度累积：用小 batch 模拟大 batch
effective_batch_size = batch_size × accumulation_steps

# 每 accumulation_steps 个小 batch 才更新一次参数
for i, batch in enumerate(dataloader):
    output = model(batch)
    loss = output.loss / accumulation_steps  #  loss缩小 accumulation_steps 倍
    loss.backward()                            # 累积梯度

    if (i + 1) % accumulation_steps == 0:     # 累积够了
        optimizer.step()                          # 更新参数
        optimizer.zero_grad()                     # 清零梯度
                        
# 简化理解：梯度下降
W_q = W_q - lr * grad_Wq  # 责任大的参数，梯度大，改得也多

# 实际使用 Adam 优化器（带动量自适应调整）
m = β1 * m + (1-β1) * grad           # 一阶矩估计（动量）
v = β2 * v + (1-β2) * (grad²)       # 二阶矩估计（方差）
param = param - lr * m / (√v + ε)   # 自适应学习率更新

🛠️ 关键训练技巧

1. 学习率调度 (Learning Rate Schedule)

训练开始时学习率较小，然后逐渐增大（预热），最后逐渐减小（退火）：

# 余弦退火学习率调度
lr = lr_max * 0.5 * (cos(π * step / total_steps) + 1)

2. 梯度如何在网络中流动？

反向传播时，梯度从后往前逐层传递：

Embedding层
∇E
←
Layer 6
∇W₆
←
Layer 5
∇W₅
←
...
∇...
←
Layer 1
∇W₁
←
LM Head
∇W_lm

链式法则的工作方式：

# 假设我们想知道 W₁ 如何影响 Loss
# 需要经过 Layer1 → Layer2 → ... → Layer6 → LM Head

# 链式法则：∂Loss/∂W₁ = (∂Loss/∂h₆) × (∂h₆/∂h₅) × ... × (∂h₂/∂h₁) × (∂h₁/∂W₁)
#                = 梯度来自高层 × 每一层的局部梯度

梯度消失问题：如果网络很深，前面层的梯度会变得很小（连乘效应）。这就是为什么Transformer需要残差连接和层归一化！

3. 梯度裁剪 (Gradient Clipping)

防止梯度爆炸，限制梯度的最大范数：

# 如果梯度的 L2 范数超过 1.0，就缩放它
total_norm = torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)

if total_norm > 1.0:
    # 缩放梯度
    clip_factor = 1.0 / total_norm
    for p in model.parameters():
        if p.grad is not None:
            p.grad *= clip_factor

3. 混合精度训练 (Mixed Precision)

使用 FP16 而非 FP32 加速训练，减少显存占用：

# 使用 GradScaler 进行混合精度训练
scaler = GradScaler()

with autocast(device_type='cuda', dtype=torch.float16):
    outputs = model(input_ids)
    loss = outputs.loss

# 反向传播（自动缩放梯度，防止下溢）
scaler.scale(loss).backward()

# 梯度裁剪和参数更新
scaler.unscale_(optimizer)
torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)
scaler.step(optimizer)
scaler.update()

📈 Loss 曲线

训练过程中，loss（损失）会逐渐下降，代表模型越来越会"说话"：

训练初期
Loss ≈ 10-12
模型几乎在"乱猜"
训练中期
Loss ≈ 3-5
模型开始学到模式
训练后期
Loss < 2
模型学有所成

📝 总结

预训练 = 海量文本 → 预测下一个词 → 调整参数
目标：让模型学会语言的"规律"

🎯 预训练关键点：

  • 数据量：越多越好（通常 TB 级别）
  • 数据质量：需要清洗去噪
  • 训练目标：Next Token Prediction
  • 学习率：Warmup + Cosine Decay
  • 训练技巧：梯度裁剪、混合精度
