📚 训练流程

📖
预训练 (Pretrain)
让模型学会"完形填空"，阅读海量文本建立基础能力
👨‍🏫
监督微调 (SFT)
教模型听指令，像请家教一样微调模型
📝
LoRA 高效微调
像贴便签一样轻量级微调，大幅减少训练参数
👍
DPO 偏好优化
直接比较两个答案优劣，让模型学习什么是"好"
🎮
GRPO 强化学习
通过试错和奖励学习，像训练小狗一样

🔮 推理流程

🔮
自回归生成
像接话游戏一样逐词生成，KV Cache 加速可视化

📚 RAG 检索增强生成

🔍
检索阶段 (Retrieval)
文档分块、Embedding、向量化搜索、余弦相似度可视化
🔗
增强阶段 (Augment)
Prompt 模板组装、Reranker 重排序、上下文注入
🤖
生成阶段 (Generate)
带上下文的 LLM 生成、幻觉检测、评估指标
