🎯 注意力机制 (Self-Attention)

计算机是如何"理解"词与词之间关系的？

🎯 核心问题

当模型处理一句话时，它需要理解每个词与其他词的关系。

例如："猫坐在垫子上"

  • "猫" 和 "坐" 是什么关系？—— 主语和动词
  • "坐" 和 "垫子" 是什么关系？—— 动作和地点
  • "猫" 和 "垫子" 是什么关系？—— 动物和地点

注意力机制就是让模型学习这些关系的方法！

💡 类比：搜索引擎

注意力机制的工作方式很像搜索引擎：

🔍
Query (查询)

你搜索的关键词

"我在找什么信息？"

🔑
Key (键)

网页的关键词

"我有什么信息？"

📄
Value (值)

网页的实际内容

"实际要传递什么？"

# QKV 投影
Q = X @ W_Q  # 768 × 768 矩阵乘法
K = X @ W_K
V = X @ W_V

🚀 GQA (分组查询注意力)

MiniMind 使用了 GQA 优化：

  • 标准 Attention：每个 Q 头有独立的 K、V 头
  • GQA：多个 Q 头共享少数 K、V 头
8 个 Q 头
每个 96 维
+
4 个 KV 头
每个 96 维
=
GQA
减少显存

📝 总结

注意力 = 词与词之间的"相关性"计算
Q×K 计算相似度，softmax 归一化，×V 得到结果
