📊 词嵌入 (Embedding)

文字是如何变成计算机能"理解"的向量的？

🎯 核心问题

计算机只能处理数字，无法直接理解文字。那么，"今天天气很好" 这样的文字，如何转换成计算机能处理的数字呢？

答案就是：词嵌入 (Word Embedding) - 把每个词转换成一个数字向量。

💡 类比：地址

想象一下，词表就像一个大城市的地址簿。每个词都有一个大致的"位置"——语义相近的词，距离也相近。

🏠 生活类比

"猫" 和 "狗" 都是宠物，所以它们在"向量空间"中的位置很近。
"苹果" 和 "香蕉" 都是水果，位置也很近。
但 "猫" 和 "苹果" 距离就比较远。

📋 第一步：认识词表

词表 (Vocabulary) 就像一本字典，收录了模型认识的所有词。每个词都有一个唯一的 ID（从 0 开始编号）。

MiniMind 的词表大小是 6400，意味着它认识 6400 个不同的词元。

📐 第二步：词嵌入矩阵

词嵌入矩阵是一个 6400 × 768 的大表格：

  • 6400 行：每行对应词表中的一个词
  • 768 列：每个词被表示成一个 768 维的向量

🔍 第三步：查表过程

词嵌入的核心就是一个查表操作：

  1. 分词器把句子分成词元，得到 Token IDs
  2. 用每个 Token ID 在嵌入矩阵中找到对应的行
  3. 取出这一行的 768 个数字，就是这个词的向量表示

❓ 第四步：嵌入矩阵是哪来的？

两个关键问题：

1. 一开始是什么样的？

嵌入矩阵一开始是随机数。就像一张白纸，模型什么都不知道。

2. 训练后有什么变化？

通过反向传播，模型会自动调整这些数字。

训练完成后，语义相似的词会有相似的向量——这就是" embedding"的魔力！

训练前：随机数 → 训练后：有意义的向量

🖼️ 多模态 Embedding：统一多模态表示

对于多模态模型，核心问题是：如何让文本、图像、音频在同一个隐空间中表示，并且能相互理解？

1. 图像 Embedding：CLIP ViT 方案

通过预训练的 CLIP Vision Transformer 将图像转换为向量：

  • 图像切分成 16×16 的 patches（如 224×224 → 14×14=196 patches）
  • 每个 patch 经过 ViT 编码器得到一个向量
  • 196 个向量组成序列，输入 LLM

2. 图像 Embedding：VQ-VAE 方案

通过向量量化将图像变成"token"，每个 token 有对应的 embedding：

  • VAE Encoder 将图像压缩到离散 latent 空间
  • 量化到 codebook 中的一个 code（类似词表中的 ID）
  • 从 codebook embedding 表中查找对应的向量

3. 音频 Embedding

通过神经网络 Codec 将音频转换为向量序列：

  • 波形通过 Encodec 编码器得到多码本 tokens
  • 每帧生成 4 个 token（多层码本）
  • 查 embedding 表得到音频向量序列

💻 代码实现

PyTorch 词嵌入层
import torch
import torch.nn as nn

# 创建词嵌入层
embedding = nn.Embedding(
    num_embeddings=6400,  # 词表大小
    embedding_dim=768     # 向量维度
)

# 分词后的 Token IDs
token_ids = torch.tensor([5640, 3660, 1574])

# 查表得到嵌入向量
vectors = embedding(token_ids)

print(vectors.shape)  # torch.Size([3, 768])

📝 总结

词嵌入 = 查表操作
Token ID → 嵌入矩阵[ID] → 768维向量
