📍 位置编码 (RoPE)

为什么"我打你"和"你打架"意思完全不同？

🎯 核心问题

在自然语言中，词的顺序非常重要：

❌
"我打你"
暴力行为
✅
"你打我"
暴力行为

两句话的词完全一样，只是顺序不同，意思就完全不同了！所以，模型需要知道每个词的位置。

🔄 RoPE 旋转位置编码

RoPE (Rotary Position Embedding) 的核心思想是：把位置信息"旋转"到向量中。

🎮 交互演示：旋转向量

点击"旋转"按钮，看看位置信息如何融入向量

0°
位置 0: 0°
💡 类比：时钟

想象每个位置就像时钟上的一个刻度：

  • 位置 0 = 时针指向 12 点
  • 位置 1 = 时针指向 1 点（旋转30°）
  • 位置 2 = 时针指向 2 点（旋转60°）
  • ...

通过这种方式，向量就"记住"了自己的位置！

📐 RoPE 数学原理

RoPE 使用旋转矩阵来编码位置：

q' = q × cos(θ)
+
rotate(q) × sin(θ)

其中 θ 是位置乘以基础频率的结果。

θ = position × base^(-2i/d)

❓ 为什么选择 RoPE？

方法 原理 优点
绝对位置编码 每个位置一个向量 简单
相对位置编码 编码相对距离 外推性好
RoPE 旋转矩阵 兼容 Flash Attention
🚀 MiniMind 的选择

MiniMind 使用 RoPE，因为：

  1. 外推性好：可以处理比训练更长的序列
  2. 计算友好：兼容 GPU 加速
  3. 效果好：在长文本任务上表现优秀

💻 代码实现

RoPE 旋转位置编码
def apply_rotary_pos_emb(q, k, cos, sin):
    # q, k: 查询和键向量
    # cos, sin: 位置编码

    # 核心公式: q' = q * cos + rotate(q) * sin
    q_embed = q * cos + rotate_half(q) * sin
    k_embed = k * cos + rotate_half(k) * sin

    return q_embed, k_embed

def rotate_half(x):
    # 把向量的一半和另一半交换
    x1, x2 = x[..., :128], x[..., 128:]
    return torch.cat([-x2, x1], dim=-1)

📝 总结

位置编码 = 把位置信息"编"进向量
RoPE = 用旋转矩阵实现位置编码
