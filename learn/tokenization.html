📝 分词 (Tokenization)

计算机是如何"拆解"文字的？

🎯 核心问题

计算机只能处理数字，无法直接理解文字。那么，当我们输入 "今天天气很好" 时，计算机是怎么处理这些文字的呢？

💡 类比：拼积木

想象一下，你有一堆积木（词元），要把一句话拆成一个个小积木。每个积木就是一个 Token。

🏠 生活类比

句子 = 一句话
词元(Token) = 这句话中的每个"词"或"字"
分词 = 把句子拆成一个个小积木

🔧 BPE 算法原理

MiniMind 使用的是 BPE (Byte Pair Encoding) 算法，中文叫"字节对编码"。它的核心思想是：

  • 把每个字符作为初始的词元
  • 统计出现频率最高的字符对
  • 把它们合并成一个新的词元
  • 重复直到达到预设的词表大小

🖼️ 多模态词表：不止是文字

对于处理图像和音频的多模态模型，词表的构建方式更加复杂，需要为不同模态设计专门的编码方案。

1. 图像词表：VQ-VAE 方案

图像不能像文字一样直接分割，需要通过编码器+量化的方式将图像压缩到离散 token 空间：

  • 原图 (如 512×512) 通过 VAE Encoder 压缩 8 倍
  • 得到 64×64 的 latent 空间，每个位置是一个向量
  • 量化为 codebook 中的一个 code（词表 ID）
  • 整个图像变成一串 token IDs（类似文字分词）

2. 音频词表：Encodec 方案

音频通过神经网络 Codec 将波形压缩到离散 token 序列：

  • 原始波形通过 Encodec Encoder
  • 输出多个码本（codebook）的 token 序列
  • 外层码本编码粗粒度，内层码本编码细粒度
  • 每帧生成 4 个 token（如 MusicGen）

💻 代码实现

使用 transformers 分词
from transformers import AutoTokenizer

# 加载分词器
tokenizer = AutoTokenizer.from_pretrained('./model')

# 分词：文字 → ID 序列
text = "今天天气很好"
ids = tokenizer(text).input_ids
print(ids)  # [5640, 3660, 1574, 658]

# 解码：ID 序列 → 文字
decoded = tokenizer.decode(ids)
print(decoded)  # 今天天气很好

BPE 兼顾速度和效果 需要训练词表
