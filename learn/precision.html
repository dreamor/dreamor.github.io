📐 模型精度与量化

为什么有时用 32 位，有时用 8 位？

🎯 什么是模型精度？

模型权重本质上是一个多维向量，每个维度上的值需要用一定的位数来存储，这就是"精度"。

FP32
32 位

单精度浮点

范围: ±3.4×10³⁸

FP16
16 位

半精度浮点

范围: ±65504

INT8
8 位

8位整数

范围: -128 ~ 127

INT4
4 位

4位整数

范围: -8 ~ 7

💡 类比：称重量

FP32 = 用精密天平（精确到 0.0001 克）
FP16 = 用普通秤（精确到 0.01 克）
INT8 = 用弹簧秤（精确到 1 克）
INT4 = 用天平砝码（只能精确到 5 克）

⚡ 量化原理

量化的核心是把高精度转换为低精度，同时保留相对关系。

① 收集范围

找出权重最大值

max = 3.5

→
② 计算 Scale

缩放因子

scale = 127 / 3.5

= 36.3

→
③ 量化

转成整数

round(0.5 × 36.3)

= 18

→
④ 反量化

使用时复原

18 / 36.3

≈ 0.496

量化: q = round(x / scale)
反量化: x ≈ q × scale

❓ 为什么量化对模型影响不大？

原始分布 (FP32)

相对大小保持

量化后分布 (INT8)

分布形状不变

🔑 关键洞察：保留相对关系

模型关心的是"谁更大"，而不是"具体多少"。

例：原始 [0.12, 0.09, 0.06] → 最大是 0.12
量化后 [48, 36, 24]（按比例）→ 最大也是 48

只要相对顺序不变，模型表现就不受大影响！

📊 量化方法对比

方法 精度损失 实现难度 适用场景
PTQ (训练后量化) ~1-2% 简单 推理加速，首选
QAT (量化感知训练) ~0.5% 中等 对精度要求高
动态量化 ~2% 最简单 快速部署

📝 总结

精度 = 存储每个权重用多少位
量化 = 高精度转低精度，保留相对关系

主流模型已全面采用 FP16/BF16 训练，推理时常用 INT8/INT4
